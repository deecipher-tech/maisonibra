# Maison Ibra — Luxury Perfume Landing Page

Responsive HTML/CSS/JavaScript landing page with a cinematic video hero.

## Run
Open `index.html` in a modern browser. No build step is required.

## Replace the hero video
Put your own MP4 at `assets/maison-ibra-hero.mp4` and change the `<source>` in `index.html`.
For best results use a 16:9 or 4:5 cinematic perfume video, 1080p+, H.264 MP4, with the bottle positioned toward the right so the text remains readable on the left.

The included `maison-ibra-hero-demo.mp4` is a lightweight demo animation generated from the Maison Ibra product artwork so the page works immediately.

## Video best practices
- `autoplay muted loop playsinline` is used for reliable browser autoplay.
- A poster image provides a fallback while the video loads.
- The pause/play control is available for accessibility.
- Reduced-motion users automatically get a paused video.
